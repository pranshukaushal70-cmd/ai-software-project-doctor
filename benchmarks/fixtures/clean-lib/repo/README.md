# clean-lib

Small string and number helpers without dependencies.

## Installation

```
npm install clean-lib
```

## Usage

```js
const { range, slugify } = require("clean-lib");
range(0, 3); // [0, 1, 2]
slugify("Hello, World"); // "hello-world"
```

## Testing

```
npm test
```
